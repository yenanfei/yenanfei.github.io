rclone personal

A private file transfer application operated by Nanfei Ye using the open-source rclone tool to upload video files and public source metadata to the owner's Google Drive. It is not offered as a public service.

Privacy Policy

Last updated: October 6, 2026

Access and use. The application uses the Google Drive drive.file scope to upload, read, and manage files created by or explicitly made available to this application. It does not request access to all files in the owner's Drive.

Storage and security. Transferred files and metadata are stored in the owner's Google Drive. Authorization is performed on the owner's Mac; the resulting token is transferred to the owner's server for ongoing transfers. The server configuration is restricted to its operating-system user. OAuth client JSON copies containing the client ID and secret are currently retained on the owner's Mac and in the owner's collaboration tool for setup. These copies do not contain an access token. Collaboration tools may handle the token during setup.

Logs and retention. Transfer logs record video identifiers, file sizes, transfer status and speed, and Drive paths. Application logs currently have no automatic rotation; system logs follow the server's default retention settings. Files, configuration copies, and logs remain until removed by the owner or applicable retention settings.

Sharing. Drive files are not intentionally shared with other people or used for advertising. Transfers use Google's services. Setup may involve the owner's collaboration tools; credentials should be handled through their secure mechanisms. The application does not use Drive content to train AI models.

Control and deletion. The owner can stop the transfer service, revoke application access in Google Account settings, and remove stored files, credentials, and logs. Revoking access does not automatically delete previously stored files.

The application's use of Google API data adheres to the Google API Services User Data Policy, including Limited Use requirements.
